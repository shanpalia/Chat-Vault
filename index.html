THREE SIMPLE STEPS

How Chat Vault works

You stay in control of which chat export is imported.

1

Export a chat

In WhatsApp, open a chat and choose More → Export chat. Select Include media if you want media files too.

2

Import into Chat Vault

Choose the TXT or ZIP export using Android's file picker.

3

Browse your export

Search messages, filter by sender or date, and open supported included media files.

YOUR DEVICE, YOUR FILES

Privacy-first by design

Chat Vault works with files you choose to import. It does not silently access WhatsApp's private chat database.

🔐 App-private storageImported backups are stored in the app's private storage on your device.
☝️ You choose what to importUse Android's file picker to select the TXT or ZIP export you want to view.
📱 No live chat restorationChat Vault views exported files. It does not restore them as live conversations inside WhatsApp.
